# Jokempo 🎮

Jogo de Pedra, Papel e Tesoura desenvolvido em C# com .NET.

## Como jogar

1. Execute o projeto com o comando abaixo
2. Escolha `1` para começar ou `0` para sair
3. Digite `0` para Pedra, `1` para Papel ou `2` para Tesoura
4. O computador escolhe aleatoriamente e o resultado é exibido
5. Ao final, um placar completo da sessão é mostrado

## Como rodar

```bash
dotnet run
```

> Requer .NET 10 ou superior instalado.
